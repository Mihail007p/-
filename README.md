# Neon District

Открытый город в браузере: ночной мегаполис под дождём, угон машин, трафик, пешеходы и полиция с уровнем розыска.
Написано на **TypeScript + Three.js (WebGL2)**, без игровых ассетов — вся графика (текстуры фасадов, неон, дождь, звук) генерируется кодом.

> Это оригинальная игра в жанре open-world crime sandbox. Она не использует название, персонажей, карту или ассеты GTA — только сам жанр.

## Играть

**Способ 1 — скачать файл (проверено).**
Открой страницу файла и нажми **Download raw file** (иконка ↓ справа):
<https://github.com/Mihail007p/-/blob/v0.2.0/NeonDistrict.html>

Затем открой скачанный `NeonDistrict.html` двойным кликом в Chrome / Edge / Firefox.
Вся игра внутри одного файла: ни сервер, ни интернет после скачивания не нужны.

**Способ 2 — скачать архив репозитория (проверено, код 200).**
<https://codeload.github.com/Mihail007p/-/zip/refs/tags/v0.2.0>
Внутри архива: `--0.2.0/NeonDistrict.html` — это и есть игра.

**Способ 3 — разработка.** `npm run dev` → `http://localhost:5173`.

### Почему нет ссылки вида `*.github.io`

GitHub Pages включается только вручную: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Токен песочницы не имеет прав на настройки репозитория (API и Actions отвечают `403 Resource not accessible by integration`),
поэтому включить Pages автоматически невозможно. После ручного включения workflow
`.github/workflows/deploy-pages.yml` будет сам собирать и публиковать игру на `https://mihail007p.github.io/-/`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Продакшн-сборка: `npm run build` → статика в `dist/` (можно раздать любым статическим хостингом).
Проверка типов: `npm run typecheck`.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D` | движение пешком / газ, руль, тормоз в машине |
| `Shift` | бег на ногах |
| `Space` | ручник (дрифт) |
| `F` | сесть в машину / выйти |
| `R` | вытащить застрявшую машину |
| `M` | звук вкл/выкл |
| Мышь (клик по сцене) | осмотр камеры |

На телефоне: левая часть экрана — виртуальный стик, второе касание — вход/выход из машины.

## Что уже работает (v0.1)

- **Город**: 4×4 квартала, процедурные дома с ночной подсветкой окон, неоновые вывески, фонари, парки, разметка и переходы.
- **Атмосфера**: дождь, туман, пар над улицами, мокрый асфальт с отражениями, лужи, bloom-постобработка, ночное небо с засветкой от города.
- **Машина**: аркадная физика (сцепление, дрифт на ручнике, потеря управления на скорости), фары с реальными тенями-конусами, стоп-сигналы, брызги из-под колёс, след/наклон кузова.
- **Угон**: можно сесть в любую встречную машину — это повышает розыск; брошенная машина возвращается в трафик.
- **Трафик и пешеходы**: машины ездят по полосам и объезжают игрока, пешеходы гуляют по тротуарам и разбегаются от несущегося авто.
- **Полиция**: уровень розыска 1–5 звёзд, копы приезжают по дорогам и преследуют, мигалки светят в такт.
- **HUD**: деньги, звёзды розыска, вращающаяся миникарта, спидометр, цель, уведомления, игровые часы.
- **Звук**: процедурный (WebAudio) — дождь, гул города, двигатель по оборотам, визг шин, удары.

## Структура

```
src/
  main.ts              точка входа, стартовый экран
  styles.css           HUD и overlay
  ui/hud.ts            DOM-HUD + отрисовка миникарты
  game/
    game.ts            движок: сцена, свет, постобработка, игровой цикл
    city.ts            генерация города, коллизии, фонари, неон
    textures.ts        процедурные текстуры (асфальт, фасады, небо, дождь)
    vehicle.ts         машина: физика, свет, материалы
    character.ts       персонаж с анимацией ходьбы
    pedestrians.ts     пешеходы и их реакция на машины
    traffic.ts         трафик по полосам
    police.ts          розыск и преследование
    effects.ts         лужи и брызги
    rain.ts            дождь и туман
    audio.ts           процедурный звук
    input.ts           клавиатура, мышь, тач
```
