# Neon District

Открытый город в браузере. **Этап 1 — мир**: дневной город, по которому можно ходить и всё
рассмотреть. Транспорт, NPC и миссии — следующие этапы.

Стек: TypeScript + Three.js + Vite. Ассетов нет: все текстуры (асфальт, кирпич, штукатурка,
витрины, небо) генерируются кодом, поэтому сборка — один HTML-файл, работает офлайн.

## Играть

1. Открой <https://github.com/Mihail007p/-/blob/arena/818faa12-repo/NeonDistrict.html>
   и нажми **Download raw file** (иконка ↓ справа).
2. Открой скачанный файл двойным кликом в Chrome / Edge / Firefox (на телефоне — любой браузер).

Архив с игрой: <https://codeload.github.com/Mihail007p/-/zip/refs/heads/arena/818faa12-repo>
(внутри `NeonDistrict.html`).

## Управление

| ПК | Телефон |
| --- | --- |
| `W A S D` — идти | левый стик |
| `Shift` — бежать | кнопка RUN или стик до упора |
| мышь — камера (плавно) | правая половина экрана |
| колесо — приближение | — |
| `C` или двойной клик — камера за спину | двойной тап — камера за спину |

Чувствительность, инверсия по вертикали и авто-возврат камеры настраиваются
кнопкой **⚙** и сохраняются в браузере.

## Что уже есть

- **Дневной город 330×330 м**: 6×6 кварталов, 74 здания с настоящими фасадами (кирпич,
  штукатурка, бетон, стекло), уступы этажей, карнизы, балконы, витрины первых этажей.
- **Три высотки-ориентира** (50–72 м), панорама города на горизонте.
- **Улицы**: асфальт с нормалями, бордюры, тротуары, разметка, переходы, фонари, светофоры,
  припаркованные машины, придомовые деревья, три парка со скамейками.
- **Освещение**: солнце с тенями, небо как environment map — стекло и краска отражают небо.
- **Персонаж**: третье лицо, анимация ходьбы и бега, коллизии со зданиями, деревьями и машинами.
- **Производительность под телефон**: вся статика слита в ~15 draw call'ов, теневые карты
  2048 и ниже на мобильных, авто-подстройка pixel ratio и FOV.

## Разработка

```bash
npm install
npm run dev         # http://localhost:5173
npm run typecheck   # tsc --noEmit
npm run test:camera # тесты камеры (jsdom, 12 проверок)
npm run build       # → docs/index.html (один файл); копия кладётся в NeonDistrict.html
```

### Камера: как проверяется

`npm run test:camera` компилирует `src/camera.ts` и `src/input.ts`, поднимает jsdom
и прогоняет реальные события мыши и касаний. Проверяется, в частности:

- после отпускания мыши/пальца камера **не двигается вообще** (drift = 0.000°);
- поворот 1:1 с движением руки в обычном темпе и сжатие при резком флике;
- отсутствие дрейфа при нулевом вводе (3 с);
- авто-возврат за спину только при ходьбе и после 2.4 с без вмешательства;
- одинаковый результат на 30 и 60 FPS.

Структура:

```
src/
  main.ts              движок: сцена, камера, цикл, качество под устройство
  player.ts            персонаж, анимация, коллизии
  input.ts             клавиатура, мышь, сенсорный стик и обзор
  ui/hud.ts            миникарта, компас, название района
  world/
    layout.ts          единая геометрия города (дороги, кварталы, спавн)
    buildings.ts       генерация зданий, тротуаров, разметки (батчинг)
    props.ts           деревья, фонари, светофоры, машины (инстансинг/батчи)
    textures.ts        процедурные текстуры
    sky.ts             дневное небо и environment map
    world.ts           сборка мира, солнце, туман
    build/geom.ts      сборщик геометрии и seeded random
```
